# Project Arc — Genesis to AG/1 to the Level-3 Boundary

**Status:** reader orientation / non-canonical summary  
**Authority:** the chapter artifacts, ablation artifacts, frozen architecture, transport artifacts, and T10 protocol artifacts remain the source of record

This document explains the whole project in plain language. It does not replace the evidence trail.

---

## 1. What the project actually did

The project began by reading **Genesis 1–50 as provenance-bound structured narrative data rather than beginning with a theological interpretation**.

The first question was deliberately modest:

> What happens, who knows what, what gets said or represented, what gets promised, what is actually done, what changes, and what remains unresolved?

The governing boundary was:

```math
\boxed{
\text{TEXT}
\neq
\text{STRUCTURAL PARSE}
\neq
\text{INTERPRETATION}
}
```

This is not a claim that Genesis is secretly a machine-learning manual, nor a replacement for theological or literary reading. Genesis was used as a large adversarial corpus whose stories repeatedly punish careless collapsing of distinct informational roles.

---

## 2. The distinction pressure from Genesis

Again and again, the text required distinctions such as:

```text
what happened
≠ what someone observed
≠ what someone was told
≠ what someone represented
≠ what someone inferred
≠ what someone later reported
```

Concrete examples include:

```text
Joseph is alive while Jacob represents Joseph as dead.

Joseph recognizes his brothers while they do not recognize him.

Isaac receives conflicting identity signals and reaches the wrong identification.

A genuine object can be present while its provenance or causal history is misunderstood.

A warning can be given without being accepted.

A future statement can exist without already being a realized event.

A promise, oath, request, authorization, and completed action can remain distinct.

An instruction can be issued without being executed.

An action can begin and be interrupted before completion.

A search can occur without locating the object searched for.

A later retrospective account can add meaning or causal attribution without erasing the earlier event record.
```

The recurring compression became:

```math
\boxed{
\textbf{what happened}
\neq
\textbf{what was observed}
\neq
\textbf{what was represented}
\neq
\textbf{what was inferred}
}
```

The most important consequence was simple:

```math
\boxed{
\textbf{the world is not the model of the world.}
}
```

---

## 3. Why the initial ontology shrank

The early structural work used a large vocabulary: entities, states, events, time, access, evidence, authority, commitments, obligations, predictions, actions, and many other categories.

The abstraction phase then asked a different question:

> Which of these need to be **architectural primitives**, and which are recoverable views over something smaller?

The rule was:

```math
\boxed{\textbf{preserve first; quotient later}}
```

and a candidate could be deleted only if the corpus-required distinctions remained reconstructible without smuggling the deleted primitive back under another name.

The resulting reductions were:

| Earlier concept | Frozen reconstruction |
|---|---|
| `ENTITY` | referential equivalence over provenance-bearing relation-argument occurrences |
| `STATE` | relational slice/view over history |
| `EVENT` | addressable relation motif / occurrence pattern |
| `TIME` | source-earned temporal relation families such as `BEFORE`, duration, calendar index, age, and overlap |
| `ACCESS` | concrete information-bearing relations such as seeing, hearing, receiving, recognizing, remembering, or discovering |
| `COMMITMENT` | local predicates such as promise, oath, surety, request, and fulfillment |
| `AUTHORITY` | topology of proposal, command, permission, appointment, refusal, allocation, and execution relations |
| `EVIDENCE` | objects/observations + histories + provenance + representation/inference relations |

The same physical referent can also persist while its relational function changes. A stone can later function as a pillar or memorial; a garment can become evidence; a pledge token can later authenticate provenance. Persistent referent does not require persistent function.

---

## 4. Why REPRESENTATION survived

`RELATION` survived because typed predication/incidence could not be removed without losing source-required structure.

`REPRESENTATION` survived for a different reason: Genesis contains structured content that must exist **without being promoted into historical truth**.

Let `\mathcal H` be the historical assertion graph and `\rho` a representation scope. Then:

```math
\boxed{
r\in content(\rho)
\not\Rightarrow
r\in\mathcal H
}
```

This is what allows the architecture to preserve simultaneously:

```text
history:
    Joseph is alive

representation:
    Jacob represents Joseph as dead
```

without making the historical graph contradictory.

The same mechanism supports reports, fears, dreams, forecasts, accusations, hypotheses, counterfactuals, plans, questions, and later causal explanations without granting their internal content automatic world-truth status.

---

## 5. The frozen Genesis architecture

After the Genesis 1–50 abstraction and adversarial ablations, the project froze:

```math
\boxed{
\mathcal A_G
=
\{RELATION,\ REPRESENTATION\}
+
\{SOURCE\_PROVENANCE,\ OPEN\}
}
```

The surviving non-meta basis among the **explicitly tested Genesis candidates** is therefore:

```math
\boxed{\textbf{RELATION + REPRESENTATION}}
```

Two additional constraints remain non-negotiable:

### SOURCE_PROVENANCE

The project must preserve where an assertion, representation, identity bridge, abstraction decision, or unresolved edge came from.

```math
\boxed{
\textbf{abstraction may reduce ontology; it may not erase evidential lineage.}
}
```

### OPEN

`OPEN` marks a deliberately unforced edge when the evidence does not license a stronger commitment.

```math
\boxed{
\text{missing}
\neq
\text{false}
\neq
\text{OPEN}
}
```

The later project sharpened this further:

```math
\boxed{
\textbf{OPEN = a reachable structural edge whose evidential path has not yet earned activation.}
}
```

So:

```math
\boxed{
\text{unknown}
\neq
\text{unasserted}
\neq
\text{unlicensed}
\neq
\text{false}
}
```

---

## 6. Why freezing mattered

Once AG/1 was frozen, **external domains were no longer allowed to teach the architecture new primitives during a test**.

The causal cut became:

```math
\boxed{
\text{Genesis-derived architecture}
\rightarrow
\text{freeze}
\rightarrow
\text{external transport tests}
}
```

An external corpus could:

```text
PASS
FAIL_RECONSTRUCTION
FAIL_HIDDEN_PARAMETER
OPEN_TEST
```

but it could not rewrite AG/1 in place merely to make itself fit.

That separation is what turns later cases into tests rather than continued architecture design.

## 7. Nine external transport tests

The frozen architecture was then taken into unrelated domains.

| Test | Domain / pressure | Verdict |
|---|---|---|
| T1 | GitLab 2017 database incident — operator model versus actual system history | `PASS` |
| T2 | OPERA/ICARUS neutrino anomaly — measurement result versus physical interpretation | `PASS` |
| T3 | Challenger — same presented evidence, competing analyses | `PASS` |
| T4 | TB testing — same observation compatible with different underlying worlds | `PASS` |
| T5 | Mars Climate Orbiter — incorrect representation drives real intervention and later evidence | `PASS` |
| T6 | Deepwater Horizon — actions change future observation/monitoring topology | `PASS` |
| T7 | Michelson–Morley / Morley–Miller — deliberate challenge selection from model-conditional predictions | `PASS` |
| T8 | Ariane 501 — nominal redundancy/validation shares failure-generating dependencies | `PASS` |
| T9 | Hubble optical failure — previously unrepresented dependency enters a later representation after investigation | `PASS` |

The strongest calibrated claim earned by this sequence is only:

```math
\boxed{
\textbf{AG/1 has survived nine heterogeneous external reconstruction tests without architectural enlargement.}
}
```

It is **not** a proof of universality, mathematical minimality, or engineering usefulness.

## 8. The recurring transport loop

Across the external cases, representation is not merely passive description. A representation can affect action, and action can change the later world and the evidence available about it.

The recurring loop is:

```math
\boxed{
\text{world}
\rightarrow
\text{representation}
\rightarrow
\text{action}
\rightarrow
\text{changed world}
\rightarrow
\text{new evidence}
\rightarrow
\text{revised representation}
}
```

Critically:

```math
\boxed{
\text{feedback}
\not\Rightarrow
\text{correct revision}
}
```

and:

```math
\boxed{
\textbf{a wrong representation can still causally change the world.}
}
```

The architecture therefore preserves the distinction between a model's truth status and its historical causal influence.

---

## 9. T9 reached the reconstruction boundary

Hubble supplied a relation that was absent from the operative pre-launch representation and present in the later post-investigation representation.

So T9 established that AG/1 can represent:

```math
\boxed{
X\notin content(\rho_t)
\qquad\rightarrow\qquad
X\in content(\rho_{t+1})
}
```

when later evidence and investigation earn `X`.

But that is still **structural discovery represented after the distinction is found**.

It does not establish:

```math
\boxed{
\text{contradiction}
\rightarrow
\text{autonomous generation of the correct missing distinction}
}
```

That is the boundary between reconstruction and the Level-3 question.

---

## 10. The Level-3 question

The operational hierarchy is now:

```math
\boxed{
\begin{aligned}
L_1 &: \text{represent a supplied distinction}\\
L_2 &: \text{recover/select a hidden distinction within a supplied hypothesis space}\\
L_3 &: \text{invent an unsupplied distinction, expose it to reality, and retract/revise it if wrong}
\end{aligned}
}
```

A valid Level-3 sequence would require:

```math
\boxed{
\text{contradiction}
\rightarrow
X_{novel}
\rightarrow
\text{prospective discriminating prediction}
\rightarrow
\text{challenge}
\rightarrow
\text{retain / retract / revise / OPEN}
}
```

The candidate must not merely be absent from the current data. It must also not have been supplied as a narrow answer family by the evaluator or challenge interface.

---

## 11. Why T10.001 was thrown away

The first blind pilot looked excellent behaviorally. The learner generated the exact hidden relation and prospectively predicted the hidden challenge outcome.

It still did **not** count.

The reason was methodological contamination: the same learner context had authored a generator whose hidden topology belonged to a narrow predefined structural family.

The exact answer was hidden, but the answer **family** was not sufficiently independent.

That produced a major methodological result:

```math
\boxed{
\textbf{hidden answer}
\neq
\textbf{hidden hypothesis space}
}
```

The project now audits separately:

```math
H_{answer},\qquad H_{family},\qquad H_{constructor}
```

and:

```math
N_{data},\qquad N_{learner},\qquad N_{constructor}.
```

`CONTAMINATED` is a first-class experimental outcome. It means the experiment failed to isolate the capability being claimed; it is not evidence that AG/1 failed.

---

## 12. Why T10.002 is UNSTARTED

The successor Level-3 protocol requires an independently admitted constructor/corpus, hidden-answer and hypothesis-family isolation, and a challenge interface whose compositional language does not smuggle in the answer ontology.

Therefore the current ledger is:

```text
T1–T9      PASS           reconstruction / transport
T10.001    CONTAMINATED   family + constructor leakage
T10.002    UNSTARTED      no independently admitted Level-3 constructor/corpus
```

The next valid state transition is not:

```text
UNSTARTED → RUNNING
```

It is:

```text
UNSTARTED → ADMITTED → RUNNING
```

only after the admission gates are actually satisfied.

This is not a scheduling inconvenience. It is part of the evidence discipline:

```math
\boxed{
\text{absence of admissible evidence}
\neq
\text{evidence of capability}.
}
```

## 13. The whole arc in one compression

The project began with a large vocabulary and ended with a small architecture:

```math
\boxed{\textbf{Small architecture. Large vocabulary.}}
```

The Bible did not hand the project a ready-made theory. Genesis acted as a difficult corpus that repeatedly forced distinctions the parser was tempted to collapse.

The deepest recurring separation is:

```math
\boxed{
\textbf{the world is not the model of the world.}
}
```

But models also act back on the world, so the full loop is:

```math
\boxed{
\text{world}
\rightarrow
\text{representation}
\rightarrow
\text{action}
\rightarrow
\text{changed world}
\rightarrow
\text{new evidence}
\rightarrow
\text{revised representation}
}
```

with one rule running through the entire project:

```math
\boxed{
\textbf{Never give a distinction more authority than its provenance has earned.}
}
```
