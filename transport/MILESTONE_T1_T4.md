# 3. World/model symmetry earned through T4

T1 established a technical instance of:

```math
\boxed{
\text{historical target}
\neq
\text{operator represented target}
}
```

T2 established:

```math
\boxed{

\neq
```

```math
\boxed{

\qquad

\qquad
\rho_A\neq\rho_B

```

so:

```math
\boxed{

\not\Rightarrow
\text{same representation}
}
```

T4 established:

```math
\boxed{

\qquad
H_1\neq H_2
}
```

so:

```math
\boxed{
\text{same local representation}
\not\Rightarrow
\text{same underlying world}
}
```

Together:

```math
\boxed{
\textbf{world/history and representation are non-equivalent in both tested directions.}
}
```

This is an empirical transport result over the bounded test set, not a universal theorem.

# 5. Next orthogonal pressure — closed-loop representation

Transport 05 changes the failure mode again.

The target is:

```math
\boxed{
\rho_t
\rightarrow
a_t
\rightarrow
\mathcal H_{t+1}
\rightarrow
o_{t+1}
\rightarrow
\rho_{t+1}
}
```

where:

```text
1. an agent/system holds or uses a representation;
2. an action/intervention is selected in relation to that representation;
3. the action changes the historical world;
4. new evidence becomes available from the changed world;
5. later representation differs from the earlier one.
```

The adversarial form should preferably include:

```math
\boxed{
\text{incorrect or materially incomplete representation}
\rightarrow
\text{real intervention}
\rightarrow
\text{real world consequence}
}
```

followed by revision from new evidence.
