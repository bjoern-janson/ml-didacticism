## What the nine tests cumulatively pressure

The transport sequence moves through increasingly active information structure:

```text
world/model mismatch
→ measurement/interpretation separation
→ competing analyses
→ observational non-identifiability
→ representation-driven action
→ action changes observation topology
→ deliberate challenge selection
→ challenge dependence / common mode
→ discovery of previously unrepresented topology
```

A recurring loop is:

```math
\boxed{
\text{world}
\rightarrow
\text{representation}
\rightarrow
\text{action}
\rightarrow
\text{changed world}
\rightarrow
\text{new evidence}
\rightarrow
\text{revised representation}
}
```

with:

```math
\boxed{\text{feedback}\not\Rightarrow\text{correct revision}.}
```

T9 reaches an important boundary: the architecture can represent that a previously absent relation became represented after investigation. That is **structural discovery represented**, not yet **structural invention generated**.
