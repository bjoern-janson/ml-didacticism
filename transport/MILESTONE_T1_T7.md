# 4. Next orthogonal pressure — T8

Transport 08 attacks **challenge independence**.

T7 established that a challenge can be selected because represented outcomes differ across live alternatives.

T8 asks whether the challenge or validation path itself can share a dependency with the system/model under test, weakening or defeating the apparent discrimination.

Target structure:

```math
\boxed{
DEPENDS(primary,X)
\qquad
DEPENDS(challenge,X)
}
```

or:

```math
\boxed{
MODEL_A\rightarrow X
\qquad
MODEL_B\rightarrow X
\qquad
CHALLENGE_C\rightarrow X
}
```

such that:

```math
\boxed{
\text{apparent redundancy / validation}
\neq
\text{independent challenge}
}
```

The architecture must attempt to reconstruct this using ordinary typed relations plus representation scopes.

Forbidden new primitives include:

```text
INDEPENDENCE
ASSUMPTION
CONFOUND
IDENTIFIABILITY
EXOGENOUS_TEST
COMMON_MODE_FAILURE
VALIDATION_STATE
```

as architecture species.

Source-earned predicates with those local meanings remain allowed.
