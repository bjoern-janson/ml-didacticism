# 4. Next orthogonal pressure — T9

Transport 09 changes the failure mode from **known topology** to **missing topology**.

T8 asked whether a known dependency undermining challenge independence can be represented as ordinary relations.

T9 asks whether a later investigation can introduce a source-supported relation that was absent from the earlier representation:

```math
\boxed{
X\notin content(\rho_t)
\qquad\text{and later}\qquad
X\in content(\rho_{t+1})
}
```

where `X` is not merely a changed value of an already represented variable, but a newly represented relation/dependency in the model topology.

Target structure:

```math
\boxed{
\rho_t
\rightarrow
challenge/test
\rightarrow
unexpected\ observation
\rightarrow
investigation
\rightarrow
\text{new source-supported relation }X
\rightarrow
\rho_{t+1}
}
```

The architecture must preserve:

```math
\boxed{
\text{not represented before}
\neq
\text{represented false before}
}
```

and:

```math
\boxed{
\text{new relation discovered}
\neq
\text{old relation assigned a new value}
}
```

without adding:

```text
STRUCTURAL_NOVELTY
INTERFACE_INVENTION
RELATION_DISCOVERY
ONTOLOGY_CHANGE
MODEL_EXPANSION
```

as new architecture primitives.

Source-earned predicates with those local meanings remain allowed.
