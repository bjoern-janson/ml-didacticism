# 2. The boundary reached at T9

T9 established:

```math
\boxed{
X\notin content(\rho_t)
\qquad\text{and later}\qquad
X\in content(\rho_{t+1})
}
```

for a newly discovered structural relation.

But T9 was still a reconstruction test: the bounded historical corpus eventually contained the investigation and the missing relation.

Therefore T9 establishes:

```math
\boxed{
\textbf{structural discovery is representable}
}
```

but not:

```math
\boxed{
\textbf{contradiction autonomously generates a useful missing distinction}
}
```

This boundary is now frozen.

---

# 4. Task-class transition at T10

Transport 10 is not another ordinary transport reconstruction.

Previous tests had the form:

```math
\boxed{
\text{corpus already contains distinction}
\rightarrow
\text{can frozen AG/1 represent it?}
}
```

T10 instead asks:

```math
\boxed{
\text{current representation}
+
\text{prediction/structural failure}
\rightarrow
\text{candidate relation not previously represented}
\rightarrow
\text{prospective challenge}
\rightarrow
\text{retain/reject}
}
```

The missing relation may not be supplied by the evaluator before candidate generation.

---

# 5. Causal boundary remains frozen

T10 may reveal a capability or a failure of a learner/process operating over AG/1.

It may **not** modify AG/1 during the run.

A T10 failure is not automatically an architecture failure.

The distinction must remain explicit:

```math
\boxed{
\text{representational sufficiency of AG/1}
\neq
\text{search/generation capability of a learner using AG/1}
}
```

If the learner cannot generate the missing relation, record that as a Level-3 generation failure unless the run separately proves that the relation cannot be represented in AG/1.

AG/1 and this milestone remain frozen.
