# Fossil — OPEN as Epistemic Licensing Boundary

**Status:** FROZEN CONCEPTUAL FOSSIL  
**Architecture:** `AG/1 = {RELATION, REPRESENTATION} + {SOURCE_PROVENANCE, OPEN}`  
**Current frontier:** `T1–T9 = PASS`, `T10.001 = CONTAMINATED`, `T10.002 = UNSTARTED`

---

# 1. Governing invariant

```math
\boxed{
\textbf{A transition can be structurally available without being epistemically licensed.}
}
```

A possible transition may be representable and reachable while remaining inactive because the evidential path required to authorize it has not been established.

This is the role carried by `OPEN`.

---

# 2. OPEN is not generic uncertainty

Preserve the distinction:

```math
\boxed{
\text{unknown}
\neq
\text{unasserted}
\neq
\text{unlicensed}
\neq
\text{false}
}
```

These are not interchangeable states.

`OPEN` does not mean:

```text
false
unknown in every respect
missing data to be guessed
permission to fill an edge heuristically
```

It marks a deliberately unforced structural edge whose activation has not been earned by the required evidence/provenance path.

---

# 3. Epistemic licensing structure

A candidate transition can be represented relationally:

```text
CANDIDATE_TRANSITION(T)
REQUIRES(T,condition_set)
REQUIRES(T,provenance_condition)
NOT_YET_ESTABLISHED(condition_set)
```

without asserting:

```text
AUTHORIZED(T)
EXECUTED(T)
```

Thus no special uncertainty object is required.

A derived view may ask whether all source-earned authorization conditions have been met.

---

# 4. Recursive symmetry

The same discipline survives at every level:

```math
\boxed{
\begin{aligned}
\text{representation} &\neq \text{truth}\\
\text{prediction} &\neq \text{realization}\\
\text{proposal} &\neq \text{authorization}\\
\text{authorization} &\neq \text{execution}\\
\text{observation} &\neq \text{interpretation}\\
\text{candidate} &\neq \text{validated candidate}\\
\text{possible experiment} &\neq \text{admissible experiment}\\
\text{admissible experiment} &\neq \text{executed experiment}
\end{aligned}
}
```

The research apparatus is therefore subject to the same distinction discipline that it uses to analyze external systems.

# 5. T10.002 as negative control on the researchers

Current state:

```text
T10.002 = UNSTARTED
```

because:

```math
\boxed{
\text{no admissible independent constructor}
\Rightarrow
\text{no valid Level-3 evidence}
}
```

and:

```math
\boxed{
\text{absence of admissible evidence}
\neq
\text{evidence of capability}
}
```

The existence of a possible experiment does not authorize its execution.

Researcher ingenuity is not itself admissibility evidence.

Therefore:

```math
\boxed{
\text{possible next action}
\neq
\text{authorized next action}
\neq
\text{executed next action}
}
```

The refusal to manufacture an admissible-looking T10.002 instance is itself a negative control on the experimenters.
