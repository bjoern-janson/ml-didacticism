# Decoder D1 — Frozen Calibration State

**Status:** FROZEN  
**Calibration set:** Genesis 1–2 canonical re-derivation audits  
**Held-out test:** Genesis 3  
**Purpose:** structural decoder admission rules after Genesis 1–2 calibration

The calibration transition is:

```math
\boxed{
D_0
\xrightarrow{\text{Genesis 1--2 calibration}}
D_1
\;\Big|\;
\text{FREEZE}
}
```

No Genesis 3 evidence may revise `D_1`.

---

## 1. Objective

```math
\boxed{
\max(\text{recoverable textual structure})
\quad
\text{s.t.}
\quad
\min(\text{unsupported formal commitment})
}
```

The decoder must avoid both failure modes:

```text
false structural promotion
missed recoverable structure
```

The trivial policy

```math
\boxed{\text{everything}=\mathrm{OPEN}}
```

does not satisfy the objective because it destroys recoverable structure.

---

## 2. Governing admission rule

```math
\boxed{
\text{weaker textual relation}
\not\Rightarrow
\text{stronger formal type}
}
```

A stronger formal type is admissible only when the text supplies the bridge required for that strengthening.

The decoder therefore prefers the weakest type sufficient to preserve the recoverable textual relation.

---

## 3. Operational rules

### D1. Textual support

```math
\boxed{
\text{Every formal object requires recoverable textual support.}
}
```

### D2. Weakest sufficient type

```math
\boxed{
\text{Use the weakest type sufficient to encode that support.}
}
```

### D3. No unsupported edge strengthening

```math
\boxed{
\text{Never strengthen an edge without a textual bridge.}
}
```

### D4. Modality separation

```math
\boxed{
\text{mentioned}
\neq
\text{conditionalized}
\neq
\text{permitted}
\neq
\text{executable}
\neq
\text{performed}
}
```

In particular:

```math
\boxed{
\text{conditional mention of an action}
\neq
\text{constituted action space}
}
```

### D5. Prospective statement is not predictive belief

```math
\boxed{
\text{prospective statement}
\neq
\text{predictive belief}
}
```

A future-oriented consequent may be recorded neutrally without assigning it to an agent belief state or a prediction object.

### D6. Typed relational edges

Do not collapse distinct backward-looking or explanatory relations.

```math
\boxed{
\text{reason}
\neq
\text{source attribution}
\neq
\text{proximate transition source}
\neq
\text{material provenance}
\neq
\text{mechanism}
}
```

Preserve the relation type on the edge rather than compressing these relations into one generic causal/provenance bucket.

### D7. Coverage before theory growth

Repeated textual operations should increase textual coverage rather than automatically increase theoretical vocabulary.

Examples already exposed by calibration include:

```text
result marker
evaluation
blessing + imperative
speaker → addressee
negative-result structure
reason / purpose connective
placement / transfer
role vacancy / role occupancy
```

Their presence licenses recording those textual relations. It does not by itself license a larger ontology.

### D8. OPEN is a successful parse state

```math
\boxed{
\mathrm{OPEN}
\neq
\text{parse failure}
}
```

Instead:

```math
\boxed{
\mathrm{OPEN}
=
\text{successful identification of an evidence boundary}
}
```

Use `OPEN` when the text does not supply the bridge required for a stronger classification.

## 6. Held-out Genesis 3 protocol

Genesis 3 is not calibration material for `D_1`.

The test is:

```math
\boxed{
D_1 + T_{\mathrm{GEN.3}}
\rightarrow
P_3
}
```

where `P_3` is a new structural parse produced under frozen `D_1`.

The sequence is:

```text
1. Freeze D1.
2. Constitute the canonical Genesis 3 substrate slice.
3. Parse Genesis 3 using only D1 admission rules and the canonical text.
4. Freeze P3 before scoring or revision.
5. Score:
   - false structural promotion
   - missed recoverable structure
6. Record held-out failures without editing D1.
7. Only afterward may held-out findings become candidate input to D2.
```

Critical invariant:

```math
\boxed{
D_2\text{ may learn from Genesis 3, but }D_1\text{ never does.}
}
```

No Genesis 3-derived concept, repair, or interpretation may be back-propagated into this frozen decoder.

## 8. Freeze statement

`D_1` is frozen at this document state before any Genesis 3 run.

No further conceptual changes are admissible before the held-out parse.

Any later decoder change must be versioned as `D_2` or another successor. `D_1` remains immutable evidence about the decoder state used for the Genesis 3 test.
