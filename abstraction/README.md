
## Deletion summary

| Candidate | Frozen verdict |
|---|---|
| `ENTITY` | derived as referential-equivalence structure |
| `STATE` | derived as relational slice/view |
| `ACCESS` | derived from concrete information-bearing relations |
| `EVENT` | derived as relation motif / occurrence structure |
| `TIME` | derived from source-earned temporal relation families |
| `COMMITMENT` | derived from local promise/oath/surety/etc. relations |
| `AUTHORITY` | derived from proposal/permission/command/allocation/execution topology |
| `RELATION` | survives |
| `REPRESENTATION` | survives |

The point is not that state, events, entities, authority, or commitments are unreal or useless concepts.

It is only that this tested representation architecture did not require each one as an independent primitive carrier.

---

## Why REPRESENTATION survives

The history graph must not be contaminated by false, future, hypothetical, reported, feared, or retrospectively inferred content.

So for a representation scope `\rho`:

```math
\boxed{
r\in content(\rho)
\not\Rightarrow
r\in\mathcal H
}
```

This permits, for example:

```text
history:        Joseph alive
representation: Jacob → Joseph dead
```

without asserting both as world truths.
