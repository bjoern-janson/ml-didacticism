## What this corpus was trying to preserve

Across Genesis, recurring non-collapse rules include:

```math
\boxed{
\text{what happened}
\neq
\text{what was observed}
\neq
\text{what was represented}
\neq
\text{what was inferred}
}
```

and distinctions such as:

```text
request ≠ promise ≠ oath ≠ fulfillment
instruction ≠ execution
prediction ≠ realization
search ≠ finding
object presence ≠ object provenance
observation ≠ interpretation
report ≠ reported event
later meaning ≠ rewritten past
```

The information-heavy chapters also repeatedly require multiple agent-relative representations of one history.

The cleanest compression is:

```math
\boxed{\textbf{The world is not the model of the world.}}
```
