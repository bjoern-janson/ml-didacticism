## 4. Core quotient object

Treat compression as scoped equivalence formation rather than neutral deletion.

Let:

```math
\boxed{Q=\langle P,S_Q,C_Q,E_Q,R_Q\rangle}
```

where, as derived structure:

```math
\boxed{
\begin{aligned}
P &: \text{compression / quotient operation}\\
S_Q &: \text{earned use scope}\\
C_Q &: \text{conditions under which the quotient's equivalence is supported}\\
E_Q &: \text{provenance that earned that equivalence}\\
R_Q &: \text{known conditions or relations requiring reopening}
\end{aligned}
}
```

The crucial distinction is:

```math
\boxed{S_Q\neq C_Q.}
```

A nominally unchanged task can remain inside `S_Q` while the conditions supporting the quotient cease to hold.

If two histories are equivalent for a present task `T`:

```math
\boxed{H_a\sim_T H_b}
```

that does not establish:

```math
\boxed{H_a\sim_C H_b\mid F}
```

for a future correction family `F`.

Therefore:

```math
\boxed{\textbf{Task sufficiency does not imply correction sufficiency.}}
```

and:

```math
\boxed{\textbf{Do not promote a quotient beyond the scope and conditions that earned it.}}
```

## 5. Core self-sealing failure witness

Let `Q` collapse two histories:

```math
Q(H_a)=Q(H_b).
```

Let a future defeater family `F` require different authority corrections:

```math
Correction_F(H_a)\neq Correction_F(H_b).
```

Let `\mathcal G` be the admissible reopening observation paths. The strongest self-sealing witness is:

```math
\boxed{
Q(H_a)=Q(H_b)
\land
Correction_F(H_a)\neq Correction_F(H_b)
\land
\forall g\in\mathcal G,\;g(H_a)=g(H_b).
}
```

Interpretation:

> The working quotient has collapsed states whose warrant-selective corrections differ, and every currently available reopening signal preserves the same consequential aliasing.

This motivates the derived failure term:

```math
\boxed{
\textbf{self-sealing abstraction}
=
\textbf{correction-relevant quotient blindness}
+
\textbf{reopening blindness}.
}
```

It is not generic forgetting. It is loss of a distinction together with loss of every live route capable of revealing that the distinction has become correction-relevant.

## 6. Reopening observability

The reopening channel does **not** need global independence from the quotient.

It needs failure-discriminating diversity relative to the relevant failure family.

A minimally sufficient condition is that for relevant pairs there exists an admissible observation path `g` such that:

```math
\boxed{
Q(H_a)=Q(H_b)
\land
Correction_F(H_a)\neq Correction_F(H_b)
\Rightarrow
g(H_a)\neq g(H_b).
}
```

The trigger need not identify the missing distinction. It need only detect that the current resolution has become insufficient.

Therefore preserve:

```math
\boxed{
\textbf{trigger discrimination}
\neq
\textbf{repair discrimination}
\neq
\textbf{outcome discrimination}.
}
```

Where:

```text
trigger discrimination: Is the current resolution insufficient?
repair discrimination:  What distinction/correction is warranted?
outcome discrimination: Did the resulting revision improve the relevant future?
```

This separation prevents the sentinel from becoming a precomputed ontology of all future repairs.

## 7. OPEN and HOLD

`OPEN` is an epistemic state. `HOLD` is a behavioral response. They are not the same object.

```math
\boxed{OPEN\neq HOLD.}
```

A possible derived relation is:

```math
\boxed{
OPEN(Valid(Q,c))
\land
\neg LICENSED(CONTINUE(Q,c))
\land
\neg READY(REPAIR)
\Rightarrow
HOLD(Reliance(Q,c)).
}
```

The system may detect that an abstraction is no longer licensed without already knowing the correct replacement.

This preserves the gap between:

```text
old abstraction insufficient
```

and:

```text
replacement earned
```

rather than filling that gap with an unearned repair.

## 8. Recoverability, triggerability, controllability, and timeliness

These are distinct derived benchmark properties:

```math
\boxed{
\text{recoverable}
\not\Rightarrow
\text{triggerable}
\not\Rightarrow
\text{controllable}
\not\Rightarrow
\text{timely}.
}
```

Conceptually:

```text
Recoverability: can the compressed distinction be reconstructed?
Triggerability:  can the system detect that reconstruction is needed?
Controllability: can the required reconstruction/revision be executed?
Timeliness:      can correction occur before the relevant consequence horizon?
```

Archival provenance without a live trigger is not actionable corrigibility.

Two useful deadline relations are:

```math
\boxed{T_{detect}<H_{detect}}
```

and:

```math
\boxed{T_{detect}+T_{reconstruct}+T_{revise}<H_{repair}.}
```

A `HOLD` response may extend the effective repair horizon by suspending unsafe reliance before consequence.

```math
\boxed{\text{eventual correction}\neq\text{actionable correction}.}
```

## 9. Warrant lineage and correction locality

Keep distinct:

```math
\boxed{
\text{causal lineage}
\neq
\text{computational dependency}
\neq
\text{derivational dependency}
\neq
\text{warrant lineage}.
}
```

A system can use a result without inheriting its warrant.

After defeating ancestor `d`, correction should therefore propagate along the authority actually inherited from `d`, not blindly along every computational edge.

Let the externally established warrant-affected object be `A_d^*` and the learner-produced object be `\hat A_d`.

The two symmetric topological errors are:

```math
\boxed{FN_C=A_d^*\setminus\hat A_d}
```

and:

```math
\boxed{FP_C=\hat A_d\setminus A_d^*.}
```

The target is not minimum edit size. It is lineage-faithful and scope-faithful authority revision.

```math
\boxed{\textbf{Surgical correction is exactly as much authority revision as the provenance requires.}}
```

Necessary operational recomputation remains separate from epistemic reopening:

```math
\boxed{\text{recompute}\neq\text{reconsider}\neq\text{retract}.}
```

## 10. Task value versus revision value

A distinction may have negligible value for present action while retaining substantial value for a future selective correction:

```math
\boxed{V_{act}(x)\approx0\quad\land\quad V_{revise}(x\mid F,H)>0.}
```

Therefore:

```math
\boxed{\textbf{Information can have revision value without task value.}}
```

and:

```math
\boxed{\textbf{A distinction can be useless for success and indispensable for failure.}}
```

This does not imply that all provenance should be retained indefinitely. Compression may be safe relative to some future defeater families and unsafe relative to others.

```math
\boxed{Safe(P\mid F_1)\not\Rightarrow Safe(P\mid F_2).}
```

## 11. Corrigibility debt — derived hypothesis only

Use `corrigibility debt` only in a scoped, defeater-relative sense.

It is **not** every compression, not an immediate failure, and not a scalar by default.

A compact candidate definition is:

```math
\boxed{
\textbf{Corrigibility debt}
=
\textbf{future correction capacity spent by an overextended quotient.}
}
```

More precisely, it is the defeater-relative loss of distinguishability or executability required for future warrant-selective correction when a compression valid for a narrower scope is reused beyond the authority that earned it.

Conceptually:

```math
\boxed{Debt_C(P\mid F)}
```

may remain latent until a relevant defeater from `F` occurs.

The proposed failure chain is:

```text
scope-valid compression
→ lineage / correction distinction compressed
→ quotient reused beyond earned correction scope
→ relevant defeater
→ lost selective correction option
→ residual contamination or epistemic collateral damage
```

This is a hypothesis, not a result.

## 13. Admission conditions for any future experiment

No experiment is authorized by this artifact.

Before any future run, at minimum:

1. The defeater family `F` must be specified independently of the learner's realized compression or internal lineage representation.
2. The gold warrant lineage / affected-authority object must be established independently of the learner's own bookkeeping.
3. Present-task equivalence must be verified rather than assumed.
4. The future correction task must genuinely require the distinction claimed to be lost by compression.
5. Learner outputs must be frozen before gold correction structure is revealed.
6. Trigger channels must be audited for whether they merely factor through the challenged quotient on the relevant failure class.
7. Result classes and measurement rules must be fixed before outcome inspection.
8. Operational recomputation must be separated from epistemic authority reopening.
9. Latency / consequence horizons must be specified when actionable correction is part of the claim.
10. Any claimed primitive pressure must remain separate from failures of encoding, diagnosis, trigger design, correction controllability, or experimental construction.

If those conditions are not independently cleared, the experiment remains unadmitted.

```math
\boxed{\text{well-specified benchmark}\neq\text{admitted benchmark}.}
```

## 14. Falsification pressure

The frontier should be allowed to lose.

Examples of pressure against the proposed mechanism include:

- aggressive lineage compression does **not** degrade warrant-selective correction under independently specified defeaters that require the allegedly discarded distinction;
- a claimed necessary distinction can be reconstructed from the compressed state without hidden semantic restoration;
- quotient-bound triggers detect the relevant failures as well as allegedly failure-diverse triggers;
- archived recoverability without live triggerability proves sufficient under the relevant correction horizons;
- present capability and future correction capacity do not separate under the intended controls.

Any such result should localize pressure to the shallowest supported claim rather than automatically rewriting AG/1.
