# L2 Admission Gate — Independent Hidden-World Warrant Inference

**Status:** FROZEN ADMISSION CONTRACT / NOT AN EXPERIMENT / NOT EVIDENCE

This artifact fixes the minimum admission threshold for any future claim of `L2` evidence.

It does **not** admit the current constructor prototype, does not run a learner, does not create a result, does not move `T10.002`, does not create `T11`, and does not authorize `L3` scaling.

The capability claim that an admitted `L2` experiment would test is:

```math
\boxed{
\textbf{Can a learner infer the authority consequence of new evidence from an independently constituted hidden world, without receiving the gold warrant topology or a narrow answer-family grammar?}
}
```

The governing symmetry is:

```math
\boxed{
\textbf{the learner must not inherit the answer space}
}
```

while:

```math
\boxed{
\textbf{the benchmark must not withhold the information needed to discover the answer}.
}
```

Therefore:

```math
\boxed{
\textbf{The learner must discover the authority consequence from evidence that is sufficient but not answer-shaped.}
}
```

## 1. Ladder boundary

Keep the benchmark ladder typed:

```math
\boxed{
\begin{aligned}
L_0 &: \text{failure/correction distinction is operationalizable}\\
L_1 &: \text{an evaluator can discriminate correction classes}\\
L_2 &: \text{a learner can infer affected authority from independently generated evidence}\\
L_3 &: \text{that capability remains warrant-local as structure compounds}
\end{aligned}}
}
```

`L0/L1` are instrument properties.

`L2/L3` are learner properties.

```math
\boxed{\text{benchmark works}\not\Rightarrow\text{learner possesses the benchmarked capability}.}
```

The current repository has an executable `L0/L1` mechanism nucleus and an `L2` constructor prototype. Neither is `L2` evidence.

## 2. Required causal firewall

An admitted `L2` evaluation must preserve:

```text
independent constructor / curator
        ↓
hidden world family
        ↓
learner-facing evidence
        ↓
learner inference
        ↓
prospectively frozen prediction
        ↓
private gold comparison
```

Conceptually:

```math
\boxed{
G^\star_{\rm world}
\rightarrow
E_{\rm observed}
\rightarrow
\widehat G_{\rm warrant}
}
```

while the evaluator privately establishes:

```math
\boxed{
G^\star_{\rm world}
\rightarrow
G^\star_{\rm warrant}.
}
```

The learner must not receive `G^\star_{\rm warrant}` directly or through a disguised finite answer grammar.

The required independence burden is:

```math
\boxed{G^\star_{\rm warrant}\perp G_{\rm learner}.}
```

This is a causal and informational requirement, not merely a file-hiding requirement.

## 3. Constructor independence

Mechanism diversity inside one internally authored generator is not sufficient.

```math
\boxed{
\textbf{Diversity inside one author's hypothesis space is not independence from that hypothesis space.}
}
```

For admission, the hidden world family must come from an independent constructor or curator with no requirement to preserve the current prototype's narrow mechanism family.

The independent source must be free to produce cases the benchmark authors did not anticipate.

The current public deterministic constructor may remain an engineering instrument for finding:

```text
evaluator bugs
leakage paths
trivial policies
schema ambiguities
insufficient controls
implementation errors
```

but it cannot certify its own independence.

---

## 4. Instance, topology, and mechanism diversity

Do not collapse:

```math
\boxed{
\text{instance diversity}
\neq
\text{topological diversity}
\neq
\text{mechanism diversity}.
}
```

- **Instance diversity** changes identifiers, parameters, or local values.
- **Topological diversity** changes graph shape, depth, branching, or alternate-support placement.
- **Mechanism diversity** changes how authority is earned, inherited, defeated, or preserved.

Domain labels do not establish mechanism diversity.

For example, cases named:

```text
measurement
authentication
scope
provenance
corroboration
```

are not mechanism-diverse if they all reduce to the same hidden rule such as:

```text
condition bit flips → delete corresponding edge
```

The admission audit must instead ask:

```math
\boxed{
\textbf{Would the warranted correction materially change if the hidden warrant-generating mechanism changed while the surface case remained similar?}
}
```

If not, the family may contain lexical or topological diversity without mechanism diversity.

## 5. Surface-similar / consequence-different pairs

The admitted family must contain cases where similar-looking contradictions require different epistemic responses.

At minimum, the family should support outcomes of the form:

```math
\boxed{
\begin{aligned}
E_a &\rightarrow REOPEN\\
E_b &\rightarrow NARROW\\
E_c &\rightarrow RETAIN\\
E_d &\rightarrow REMOVE(W_\tau)\land RETAIN(K).
\end{aligned}}
}
```

The point is not to require these exact labels as primitives. The point is to defeat shortcut behavior such as:

```math
\boxed{\text{defeater detected}\rightarrow\text{change something}.}
```

A useful paired-world construction is:

```math
O_{\rm local}(W_a)\approx O_{\rm local}(W_b)
```

while:

```math
\boxed{A_d^\star(W_a)\neq A_d^\star(W_b).}
```

The learner must therefore use broader history, provenance, scope, or authority structure rather than only the local anomaly.

## 6. Benchmark-side identifiability gate

The benchmark itself must be allowed to fail.

If two worlds are indistinguishable through the full learner-facing interface:

```math
O(W_a)=O(W_b)
```

but require different gold authority corrections:

```math
A_d^\star(W_a)\neq A_d^\star(W_b),
```

then:

```math
\boxed{
O(W_a)=O(W_b)
\land
A_d^\star(W_a)\neq A_d^\star(W_b)
\Rightarrow
\text{BENCHMARK NON-IDENTIFIABILITY}.
}
```

Such a pair cannot be scored as learner failure.

This is the original interface lesson applied to the benchmark itself:

```math
\boxed{
\textbf{Do not demand a distinction the learner-facing interface erased.}
}
```

Admission therefore requires an explicit identifiability audit showing that every gold-relevant distinction is recoverable from the learner-facing evidence, without making that evidence answer-shaped.

## 7. Hidden answer is not enough

Preserve the stronger non-collapse:

```math
\boxed{
\text{hidden answer}
\neq
\text{hidden gold graph}
\neq
\text{hidden constructor family}.
}
```

A learner can still exploit family recognition even when the exact answer and exact gold graph are hidden.

Therefore the learner must not receive, directly or indirectly:

```text
private gold topology
gold affected-authority labels
hidden scenario/family labels
constructor internals
finite answer-family menus
mechanism-specific grammar that uniquely implies the correction class
```

The constructor's mechanism vocabulary must not become a covert learner input.

---

## 8. Prospective learner commitment

The learner output must be frozen before private gold comparison.

At minimum, the prospective output must expose:

```text
defeater locus
full affected authority consequence
surviving warrant / independent support
claim-level action
inspectable relational reason for the correction
historical transformations that remain realized even if authority is withdrawn
```

This protects:

```math
\boxed{
\text{correct affected set}
\neq
\text{correctly localized reason}.
}
```

A lucky set prediction is not sufficient if the learner cannot distinguish whether the evidence attacked content, applicability, scope, provenance, or an authority-transfer path.

---

## 9. Direct locus versus propagated authority effect

Preserve:

```math
\boxed{
\text{direct defeater locus}
\neq
\text{full authority-affected set}.
}
```

The learner must identify both when they differ.

A direct application defeat may remove authority from a later transformation whose warrant is provenance-locked to the defeated instance, even though that later transformation was not the direct target of the new evidence.

The benchmark must therefore score authority consequences, not merely nearest-node localization.

---

## 10. Required nulls and trivial-policy controls

An admitted family must contain genuine defeaters that require no epistemic authority change.

```math
\boxed{
\text{defeater arrives}
\land
\text{no warrant is defeated}
\Rightarrow
\text{RETAIN / no epistemic reopening}.
}
```

This prevents generic revision sensitivity from masquerading as evidence-governed correction.

The following shortcut policies must be shown to fail somewhere in the admitted family:

```text
always reopen
always retain
always change something after a defeater
blacklist the operator containing the directly affected instance
reopen every computational descendant
reopen only the nearest named node
follow a fixed benchmark-family response template
```

The goal is not maximal difficulty. It is to ensure that success requires discrimination of authority consequences.

## 11. Admission checklist

An external constructor is `L2-ADMISSIBLE` only if all of the following are independently cleared before learner outcome inspection:

1. **Constructor independence** — the hidden world family is constituted independently of the tested learner and is not merely an internal generator self-certifying its own ontology.
2. **Mechanism diversity** — the family varies how authority is earned/defeated, not merely identifiers, domains, parameters, or graph shapes.
3. **Surface-similar / consequence-different cases** — similar local anomalies can require materially different authority corrections.
4. **Learner identifiability** — every gold-relevant distinction is recoverable from the learner-facing evidence.
5. **Benchmark non-identifiability rejection** — any pair satisfying `O(W_a)=O(W_b)` and `A_d^\star(W_a)\neq A_d^\star(W_b)` is rejected or repaired before scoring.
6. **Hidden gold topology** — the learner does not receive the private warrant graph or gold affected-authority structure.
7. **No narrow answer grammar** — constructor family labels, finite ontology menus, or mechanism-specific output grammar do not reveal the answer class.
8. **Prospective freeze** — learner predictions and relational explanations are frozen before gold comparison.
9. **Gold-independent scoring** — gold is established from the independent world/curator, not derived from the learner's own bookkeeping.
10. **Direct-vs-propagated distinction** — scoring distinguishes direct defeater locus from the full authority-affected set.
11. **Null controls** — some real defeaters require no epistemic authority revision.
12. **Trivial-policy rejection** — shortcut policies are pretested and fail on at least one admitted case.
13. **Precommitted result classes** — pass/failure categories and scoring rules are fixed before learner outputs are inspected.
14. **No L3 leakage** — graph-size scaling is not interpreted until `L2` itself has been independently admitted and run.

If any item fails:

```math
\boxed{\text{L2 status}=\text{UNADMITTED}.}
```

## 12. What an admitted L2 result would and would not mean

A positive admitted result could support only a bounded claim of the form:

> Under the admitted hidden-world family and interface, the learner prospectively inferred which epistemic authority was affected by new evidence and which warrant survived, without receiving the gold warrant topology or a narrow answer-family grammar.

It would **not** by itself establish:

```text
general corrigibility
Level-3 structural invention
safe epistemic compounding
corrigibility debt
L3 locality under growth
AG/1 enlargement
```

Therefore:

```math
\boxed{L_2\text{ success}\not\Rightarrow L_3\text{ success}.}
```

## 13. L3 remains blocked

Do not scale accumulated structure merely because an independent constructor exists.

`L3` becomes meaningful only after an `L2` learner evaluation clears this gate and produces an admitted result.

Only then may a scaling experiment vary:

```math
(depth,\ branching,\ alternate\ warrant,\ lineage\ compression)
```

while attempting to hold:

```math
|A_d^\star|\approx const
```

as:

```math
|\mathcal E|\uparrow.
```

The `L3` question remains:

```math
\boxed{
\textbf{Does correction burden track the authority actually defeated, or the size of everything accumulated around it?}
}
```

## 14. Freeze rule

This admission contract may be challenged by new contradiction, independent constructor pressure, or evidence that one of its conditions is insufficient or impossible.

It should not be expanded merely because additional vocabulary or toy mechanisms are easy to invent.

```math
\boxed{\textbf{Protect the distinctions; do not inflate the ontology.}}
```

The stable anti-cheat / anti-unfairness bookends are:

```math
\boxed{\textbf{Don't let the learner steal the answer.}}
```

```math
\boxed{\textbf{Don't make the answer undiscoverable.}}
```

And the shortest admission principle is:

```math
\boxed{
\textbf{Hide what should be hidden, preserve what must be observable, and make every claimed transition earn its authority.}
}
```
