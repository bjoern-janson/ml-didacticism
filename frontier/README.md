# Frontier

**Status:** OPEN research questions, explicitly non-validating return pressure, and high-value neighboring empirical evidence downstream of the frozen evidence

```math
\boxed{\textbf{Frontier artifacts may sharpen questions or pressure existing machinery; they do not modify frozen evidence or promote unearned hypotheses.}}
```

The repository's canonical derivation/validation path is:

```text
source
  ↓
derivation
  ↓
ablation
  ↓
AG/1 freeze
  ↓
independent external transport
  ↓
T10 boundary
  ↓
frontier
```

The directory roles are deliberately different:

```math
\boxed{
\begin{aligned}
\texttt{abstraction/} &: \text{derive and freeze}\\
\texttt{transport/} &: \text{expose the frozen result to independent pressure and record outcomes}\\
\texttt{frontier/} &: \text{preserve unearned questions, bounded return pressure, and neighboring evidence without authority leakage}
\end{aligned}
}
```

Therefore:

```math
\boxed{\textbf{derived question}\neq\textbf{frozen evidence}\neq\textbf{experimental result}\neq\textbf{neighboring result}.}
```

and:

```math
\boxed{\textbf{A frontier artifact may become more precise without becoming more confirmed.}}
```

Formal detail and neighboring success are not automatic authority sources.

## Motivation, derivation, validation, return

For the motivating incident, preserve four lineages:

```math
\boxed{
\begin{aligned}
M &: \text{incident}\rightarrow\text{research burden}\\
D &: \text{Genesis}\rightarrow\mathcal A_G\\
V &: \mathcal A_G\rightarrow T1\!-\!T9\rightarrow T10\text{ boundary}\\
R &: (\mathcal A_G,V)\rightarrow\text{frontier}\rightarrow\text{return to }M
\end{aligned}
}
```

Thus:

```math
\boxed{
\textbf{motivation}
\neq
\textbf{derivation}
\neq
\textbf{validation}
\neq
\textbf{return/application}.
}
```

This prevents the motivating failure from quietly pre-authorizing the ontology later used to analyze it.

## What belongs here

A frontier question artifact may preserve:

```text
question
construct
formalization
competing mechanisms
smallest failure witness
failure loci
counterexamples
admission conditions
falsification conditions
```

A return-pressure artifact may additionally preserve:

```text
source-layer typing
motivational provenance
reconstruction pressure against existing topology
source disagreements
candidate failure witnesses
explicit non-validation boundary
```

A neighboring-evidence artifact may preserve:

```text
an external empirical result close to the frontier boundary
what capability the external work actually demonstrates
what upstream interface/problem structure remains supplied
non-implications relative to T10/frontier claims
methodological parallels that sharpen admission or evaluation rules
explicit zero-transfer-of-authority boundary
```

None of these types may convert formal fit, source richness, conceptual resonance, or neighboring success into an empirical verdict merely because the analysis is detailed.

The governing transitions are:

```math
\boxed{\text{failure boundary}\rightarrow\text{question}}
```

not:

```math
\boxed{\text{failure boundary}\rightarrow\text{answer}.}
```

For motivating return pressure:

```math
\boxed{\text{problem}\rightarrow\text{question}\not\Rightarrow\text{problem}\rightarrow\text{architecture}.}
```

For neighboring evidence:

```math
\boxed{\text{neighboring success}\rightarrow\text{boundary pressure}\not\Rightarrow\text{claim inheritance}.}
```

## What can move a frontier artifact

The next evidentially meaningful change should be caused by at least one of:

```math
\boxed{\text{new contradiction}\quad|\quad\text{new independent evidence}\quad|\quad\text{actual experimental admission}.}
```

Everything else is clarification or optional polishing.

New independent evidence may improve the provenance record or sharpen pressure without automatically confirming the frontier hypothesis.

A future experiment described here remains unstarted until its own admission conditions are independently satisfied.

```math
\boxed{\text{specified}\neq\text{admitted}\neq\text{executed}\neq\text{validated}.}
```

## Architectural boundary

Nothing in this directory retroactively changes:

```text
abstraction/12_GENESIS_ARCHITECTURE_FREEZE.md
transport/MILESTONE_T1_T9.md
transport/t10/MILESTONE_T10_001_CONTAMINATION.md
transport/10B_LEVEL3_PROTOCOL_V2_HYPOTHESIS_SPACE_ISOLATION.md
```

The frozen architecture remains:

```math
\boxed{
\mathcal A_G
=
\{RELATION,\ REPRESENTATION\}
+
\{SOURCE\_PROVENANCE,\ OPEN\}
}
```

Frontier vocabulary is derived research vocabulary unless and until an independently evidenced reconstruction failure earns an architectural revision.

```math
\boxed{\textbf{New vocabulary is cheap. New primitives are expensive.}}
```

A motivating incident has no grandfathered right to fit. A future return analysis may legitimately end in:

```math
\boxed{
\text{fit}
\;|\;
\text{partial fit}
\;|\;
\text{failure}
\;|\;
\text{new distinction required}
\;|\;
OPEN.
}
```

A neighboring empirical result likewise has no right to donate its success across a different capability boundary.

```math
\boxed{\textbf{Neighboring success can sharpen a boundary without crossing it.}}
```

## Stopping rule

The frontier may be richly specified and surrounded by increasingly capable neighboring systems while remaining epistemically stationary on its own unresolved claims.

```math
\boxed{\textbf{More precision}\neq\textbf{more evidence}.}
```

and:

```math
\boxed{\textbf{Nearby capability}\neq\textbf{inherited capability}.}
```

When no evidence has earned a stronger state:

```math
\boxed{\mathrm{OPEN}.}
```

The stable provenance rule is:

```math
\boxed{\textbf{Let the problem motivate the research. Let independent evidence determine what the research is allowed to conclude.}}
```
