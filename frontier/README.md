# Frontier

**Status:** OPEN research questions downstream of the frozen evidence

```math
\boxed{\textbf{Frontier artifacts preserve questions generated by the frozen evidence; they do not modify that evidence or promote their own hypotheses.}}
```

The repository's current epistemic path is:

```text
source
  ↓
derivation
  ↓
ablation
  ↓
AG/1 freeze
  ↓
external transport
  ↓
T10 boundary
  ↓
frontier
```

The directory roles are deliberately different:

```math
\boxed{
\begin{aligned}
\texttt{abstraction/} &: \text{derive and freeze}\\
\texttt{transport/} &: \text{expose the frozen result to independent pressure and record outcomes}\\
\texttt{frontier/} &: \text{preserve precisely specified but unearned questions}
\end{aligned}
}
```

Therefore:

```math
\boxed{\textbf{derived question}\neq\textbf{frozen evidence}\neq\textbf{experimental result}.}
```

and:

```math
\boxed{\textbf{A frontier artifact may become more precise without becoming more confirmed.}}
```

Formal detail is not an authority source.

## What belongs here

A frontier artifact may preserve:

```text
question
construct
formalization
competing mechanisms
smallest failure witness
failure loci
counterexamples
admission conditions
falsification conditions
```

It must not convert those into an empirical verdict merely because the question is well specified.

The governing transition is:

```math
\boxed{\text{failure boundary}\rightarrow\text{question}}
```

not:

```math
\boxed{\text{failure boundary}\rightarrow\text{answer}.}
```

---

## What can move a frontier artifact

The next evidentially meaningful change should be caused by at least one of:

```math
\boxed{\text{new contradiction}\quad|\quad\text{new independent evidence}\quad|\quad\text{actual experimental admission}.}
```

Everything else is clarification or optional polishing.

A future experiment described here remains unstarted until its own admission conditions are independently satisfied.

```math
\boxed{\text{specified}\neq\text{admitted}\neq\text{executed}\neq\text{validated}.}
```

## Stopping rule

The frontier may be richly specified while remaining epistemically stationary.

```math
\boxed{\textbf{More precision}\neq\textbf{more evidence}.}
```

When no new evidence has earned a stronger state:

```math
\boxed{\mathrm{OPEN}.}
```
